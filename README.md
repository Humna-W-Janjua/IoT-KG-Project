This repository implements an end-to-end Knowledge-Grounded Intelligent System for IoT network traffic analysis and botnet threat detection. Building on semantic foundations from Iteration 1 and modern neuro-symbolic AI in Iteration 2, the system transforms raw IoT network telemetry (IoT-23) into a formal OWL 2 RL Knowledge Graph, performs TransE Knowledge Graph Embedding & Link Prediction, and powers a SPARQL-driven Retrieval-Augmented Generation (KG-RAG) application with explicit provenance tracking.
